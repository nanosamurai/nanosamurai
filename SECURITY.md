# Security Policy

Report suspected vulnerabilities privately by opening a GitHub security advisory
or by contacting the maintainers directly.

Do not include production secrets, customer data, access tokens, recordings, or
transcripts in public issues.

Local defaults bind published Docker ports to `127.0.0.1`. Do not change
`COMPOSE_BIND_IP` to `0.0.0.0` unless you understand and control the network
exposure.
